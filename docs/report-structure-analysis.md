# 职业病危害预评价报告结构分析

> 基于 9 份真实备案报告（长兴/浦发/正力/祺珠/格兰富/聚和/奥绮斯摩/鼎沛/波士胶）+ GBZ/T 196—2025 国家标准 + 机构资料收集单，交叉分析出的报告结构定论。
> 生成日期：2026-08-23

---

## 一、结论先行（三段话看懂）

1. **报告是「主报告 + 附录」两层架构**：主报告 1-6 章给出结论，附录 7-12 章给出详细分析支撑。附录是主报告的"展开版"（附录的工程分析=主报告第1章的深化，附录的危害识别=主报告第2章的深化）。

2. **一级/二级/三级标题高度固定**（跨 9 份报告 ≥50% 一致），**四级及更深是数据驱动**（因项目而异）。所以你看到的"三级标题不一样"其实只发生在少数数据相关小节（如工艺流程下的产品线、危害识别下的物质细分）。

3. **编号体系**：报告正文用 **1-12 章编号**（不是标准里的 10.x）。GBZ/T 196—2025 第 10.2 节规定的是"章节内容"，报告用 1-12 章呈现。主报告 1-6 章 = 标准正文结论部分，附录 7-12 章 = 标准规定的详细分析。

- 工程概况表：产品产能、建构筑物、设备清单、原辅材料、岗位定员、技术经济指标（第1/8章）
- 危害识别表：工序-密闭-物料-危害因素、工种-危害因素（2.1/10.1）
- 检测结果表：CTWA/CSTEL/CMAC检出、噪声/高温/工频电场（2.2/9.4/10.4）
- 防护设施表：防护设施配置、PPE配置（3.1/11.1/9.2）
- 检查表：卫生要求-检查依据-检查结果-评价（4章/12章各节）
- 健康影响表：危害特性-健康影响-所致职业病（10.2）
- 限值表：PC-TWA/PC-STEL/PE（10.3）
- 投资表：防治经费（4.6/12.6）

> 实现：每章叙述后紧跟该章对应的数据表（表格由数据提取引擎生成，与本项目数据对齐）。

### 6.4 生成完整度（照报告全生成）

报告 = 主报告(1-6) + 附录(7-12)，**全生成**。但基于能力约束分优先级（诚实说明）：

- **必生成**：1 建设项目概况、2 危害识别与评价、3 防护措施评价、4 综合性评价、5 补充措施、6 评价结论、7 评价依据、8 工程分析
- **按需生成**：9 类比调查（需要类比数据，无则提示"需类比企业资料"）、10 危害识别与评价（详细版）、11 防护措施分析（详细版）、12 综合分析（详细版）
- **建议 LLM 长文 + 数据表格**：每章 = 叙述段落（LLM）+ 数据表（引擎）+ 关键结论（判定引擎），照报告的"表文融合"样式

> 能力边界（诚实）：①类比检测数据 / 体检结果 / 实测接触水平 = 企业需上传真实数据，无则报告标记"待补充"（这跟真实报告"数据由企业提供"一致）；②四级产品线 / 工艺细节 = 从上传材料提取，材料不全则该级为空。

### 6.5 高亮警示 = 需人工审核（非置信度）

AI 生成的段落（尤其判定/结论类）标"⚠ 需人工审核"，样式为段落左侧细线 + 淡黄底，提示用户复核。不是表格标黄。判定引擎产生的"超标/高风险"结论用文字明确输出，不靠颜色暗示。
