## 三、关键结论

1. **两份材料都能完整支撑 11 章报告**，且都有"现状评价报告"（长兴ZPJ 71表/新泰现状评价 198表）——这是第2章现有企业概况 + 第4章类比调查 + 第5章危害分析的最强数据源。
2. **检测报告 PDF 是扫描件**（长兴125页/新泰94页+22页），但核心检测数据**已包含在现状评价报告的检测结果表里**（ZPJ表25-48、新泰表89-122），不阻塞。
3. **提取建议**：
   - 长兴：345資料.docx（环评）+ ZPJ（现状评价）+ 申请报告 → C3/C6/C7/C8/C10/C17 全覆盖
   - 新泰：申请报告 PDF（有文本层）+ 现状评价 doc → C1/C2/C3/C6/C7/C8/C10/C13/C14/C15/C17
   - 两份的现状评价 docx 都建议先提取成结构化 json（设备/检测/定员/应急/PPE），再喂给系统
4. **表格对照**：备案稿长兴40表/新泰43表；系统当前17-21张。现状评价里的表结构和备案稿几乎一致（器材表119行/药品表/洗眼点/报警器/健康效应/关键控制点），可直接提取复用。
5. **工作流**：建议先做长兴（材料最全）端到端：提取 → 上传系统 → 生成 → 对比备案稿 → 迭代提取层/表格。
